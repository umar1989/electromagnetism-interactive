# Magnetic Effects of Electric Current: interactive notes

Static site (no build step). Open `index.html` locally, or publish with GitHub Pages:
repo **Settings → Pages → Deploy from a branch → `main` / `/docs`**.

- `index.html`, `assets/style.css`, `assets/app.js`: the site (KaTeX is loaded from a CDN)
- `assets/figures/`: textbook figures
- `downloads/`: slides, handout and workbook PDFs
